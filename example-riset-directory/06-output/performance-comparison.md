# Performance Comparison

## Perbandingan No Index

Keunggulan:

- Insert cepat

Kelemahan:

- Read lambat

---

## Perbandingan Single Index

Keunggulan:

- Seimbang

Kelemahan:

- Tidak optimal pada query kompleks

---

## Perbandingan Composite Index

Keunggulan:

- Read paling cepat

Kelemahan:

- Insert lebih lambat

---

Kesimpulan:

Pemilihan strategi indexing harus disesuaikan dengan karakteristik aplikasi.
