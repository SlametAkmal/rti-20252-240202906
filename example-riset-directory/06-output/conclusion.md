# Kesimpulan

Berdasarkan hasil benchmark dapat disimpulkan bahwa strategi indexing memberikan pengaruh terhadap performa PostgreSQL.

Composite Index memberikan waktu query tercepat untuk operasi pencarian data.

Single Index memberikan performa yang relatif seimbang.

No Index cocok digunakan apabila sistem lebih banyak melakukan proses penambahan data dibandingkan pencarian.
