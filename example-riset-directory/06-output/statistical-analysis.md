# Statistical Analysis

Analisis statistik dilakukan untuk mengetahui perbedaan performa antar strategi indexing.

Parameter yang dianalisis:

- Mean
- Minimum
- Maximum
- Standar Deviasi

Statistik dihitung untuk setiap operasi CRUD pada seluruh ukuran dataset.

Hasil menunjukkan bahwa strategi Composite Index memberikan performa terbaik pada operasi Read, sedangkan No Index memberikan performa terbaik pada operasi Insert.
