# Benchmark Configuration

## Tujuan

Benchmark dilakukan untuk mengetahui performa PostgreSQL terhadap operasi CRUD pada sistem E-Commerce.

## Database

- PostgreSQL 16

## Hardware

Processor : Intel Core i5

RAM : 8 GB

Storage : SSD 512 GB

## Sistem Operasi

Windows 11 Pro 64-bit

## Ukuran Dataset

- 50.000 Record
- 100.000 Record
- 250.000 Record
- 500.000 Record
- 1.000.000 Record

## Strategi Indexing

1. No Index
2. Single Index
3. Composite Index

## Operasi

- Create
- Read
- Update
- Delete

## Parameter Pengujian

- Response Time
- Throughput
- CPU Usage
- Memory Usage
- Query Execution Time

## Replikasi

Setiap pengujian dilakukan sebanyak 10 kali kemudian dihitung nilai rata-ratanya.
